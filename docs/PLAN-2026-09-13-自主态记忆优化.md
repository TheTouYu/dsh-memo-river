## 1. 问题清单

- **P1（根）**：注入只认回合第一步（E1）。自主任务无新回合 → 读侧全盲。
- **P2**：草稿 flush 挂 turn-stopping（E3）。写侧安全网在自主态不在线。
- **P3**：dedupeRefreshTurns 按回合计数（E4 反证：交互态正常）。自主态永不触发；且与压缩事件无联动——E5 两次幸存属边界运气，无机制保证。
- **P4**：排序无近因权重（E6）。动态 K 偏好枢纽连接的旧节点，最新最相关日记被 k-limit 截掉。
- **P5**：门控锚位不一致。检索跟最近 6 条对话（随任务演化），门控钉在最后一条 user 消息（自主态=开场白，恒定）。开场白过门→橡皮章（轻）；不过门→全盲（重）。0.55 阈值仅 w1 有判别力（历史实测：w≥2 时三条无关负例全误过 0.57–0.78）。
- **P6（卫生）**：memo_write 调用计数与落地篇数不符（×3 vs 2，疑中断无日志）；微语料 regime=collapsed 无规模标注，易误读。
- **P7（行为层，非代码 bug）**：写入节律断崖（E2）——读侧注入块是写侧最佳触发器（D1 恰在开场注入尝试后落笔），P1 修复会部分自愈 P7。

## 2. 方案：四刀 + 卫生项

### 第一刀（P1+P3，读侧活命）：自主态节律注入 + 压缩联动
- `injector.ts:320` 一带：`step!==1` 改为节律判定。维护 per-session `stepsSinceUser`（claimed 无新 user 实文本则 +1）；自主态每 `autonomousInjectEverySteps`（默认 15）步跑一次完整管线。
- **压缩联动**：pre-step 时倒扫最近消息，发现 `source.plugin=compact` 的新压缩事件 → 无视节律立即重评，且**绕过 identical-selection**（压缩后是记忆最脆弱时刻）。不依赖 DSH 暴露新事件，纯消息扫描即可。
- dedupeRefreshTurns 语义扩展：自主态按"节律跳数"计数（每 8 跳强制刷新），交互态维持回合计数不变。
- 防刷屏三保险不变：同集合去重 + 刷新上限 + tokenBudget 封顶。
- 验收：hermetic 模拟自主步序列→15 步节奏触发；压缩事件→立即重注且绕过去重；交互路径字节级回归不变。

### 第二刀（P5，门控换锚）：粘性锚 + 校准实验先行
- 实验先行：用 genshin 桶漂移样本 + 本桶样本，测 assistant 锚 w1 在 0.55 的真阳性/真阴性分离度（方法同当初 0.632–0.676 vs 0.405–0.434 那轮）。过关才实现。
- 实现：锚=合格文本时才更新（交互态=当前 user 消息；自主态=最近 ≥40 字 assistant 消息），永远 w1 单条，阈值不动。粘性：无新合格文本沿用旧锚。
- 日志加 `mode=interactive|autonomous anchor=user|assistant`。

### 第三刀（P2，写侧兜底）：守护循环 interval flush
- daemon 对"运行中会话"（turn 未停）按间隔落任务摘要草稿：条件=距该桶上次成功写入 >20min 且会话有新事件。落 pending/ 走人工批准，不自动入库。
- 防积压：每会话每小时至多 1 篇草稿（genshin 17 篇积压教训）。

### 第四刀（P4，排序近因）：k-limit 近因保底
- 候选截断前：若"最近 7 天内日记"在候选集内，保底 1 席（按相关度选最新）；或给 topology 分加时间衰减。倾向前者——改动面小、可预期。
- 验收：构造"最新日记在候选尾部"用例，断言其入选。

### 卫生项（P6）
- memo_write 工具层 try/catch 全路径落日志（含中断/拒绝），消掉 ×3 vs 2 的黑洞。
- 日志 regime 旁标注语料规模（`regime=collapsed(n=2)`），防微语料误读。
