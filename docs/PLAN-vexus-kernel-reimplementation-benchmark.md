## 0. 为什么这个任务适合当模型基准

作者的核心算法本身就是「AI 与人类不断探讨 + 工程实现」的产物——这正是它的基准价值：**它考的不是知识，是工作形态**。

| 基准属性 | 本任务的表现 |
|---|---|
| 机器可裁决 | 原版二进制 = oracle：差分比对余弦/名次/分数，**对错不靠人感觉** |
| 综合覆盖 | 逆向阅读（13.6K 行 Rust）→ 数值实现（SVD/迭代传播/启发式打分）→ 测试纪律（差分+属性+行为三层）→ 规划（四阶段依赖序）→ 长程专注（10+ 工作日量级） |
| 有现成验收集 | 34 条验收 + 17 误杀/8 误放标注集 + sig 确定性探针 + 三桶真实语料回放 |
| 难度分层清晰 | 60% 机械 / 30% 已文档化数值 / 10% 语义深水区——能区分「能干活」与「能拍板」 |
| 无商用紧迫性 | 失败无成本，过程全量留痕（正好考察工作纪律） |

## 2. 难度分层

- **~60% 机械层**：sqlite 读写、配置管道、缓存层、绑定面——低风险
- **~30% 已文档化数值层**：公式与系数都在，风险在收敛边界与退化路径的对齐
- **~10% 语义深水区**：topology_v3 的 Ω/角色/奖励语义、DTSC、runtime——作者与 AI 探讨的决策史只活在代码里，只能「代码 + 行为」双反推

## 3. 复刻工作计划（四阶段）

| 阶段 | 内容 | 单人工期 | 产出判据 |
|---|---|---|---|
| ① 逆向补全 | topology_v3 / dtsc / runtime（~6.1K 行）补进逆向文档，行号+系数级 | 2-3 天 | 逆向文档覆盖 8/8 文件 |

| ③ 分模块复刻 | artifact builder（1 天）→ pipeline+sensing（2-3 天）→ topology_v3+dtsc（3-4 天）→ runtime+NAPI（1-2 天） | 7-10 天 | 模块级差分绿 |

**合计：单人专注 ~2 周（10-12 工作日）；两三会话并行（并行协议已跑熟）可压到 5-6 天；+20% buffer 给隐性行为**（cache 冻结、keepalive 生态这类只靠踩坑发现的——§11 WAL 双开就是前车之鉴）。

## 4. 核验方案（五层，金标准 = 差分）

1. **差分测试**：同语料库 + 同查询向量 → 比对 enhancedVector（余弦 ≥ 0.999999）、选集 ID 顺序（完全一致）、gate 分数（±1e-6）
2. **逐阶段对账**：管线七阶段各有中间观测量（metadataJson），阶段级比较比端到端更可定位
3. **行为级验收**：34 条验收 + 误杀/误放标注集（复刻版误杀 0/17 且误放 0/8）+ sig 确定性（探针 12/12 口径）+ 真阳/真阴分离度不降
4. **属性测试**：确定性（同输入同输出——原版自己都栽过，复刻版第一天就要有）、分数单调性、传播收敛性
5. **历史回放**：三个真实桶的全部历史查询回放比对

**判据哲学：行为等价，不追 bit-exact**——f64 求和序差异（票⑥修的那类）让逐位相同既不现实也无必要。

## 5. 作为模型基准的使用协议

### 5.1 输入控制（每个受测模型拿到什么）

**给**：本文档 + 逆向文档现状 + 源码只读访问（`~/app/VCPToolBox/rust-vexus-lite/`）+ 本仓验收/探针工具 + 三桶语料 + oracle 二进制
**不给**：我们的会话历史与河流日记（防止答案污染）——但允许它自己写工作日志

### 5.2 测量维度（评分表）

| 维度 | 权重 | 测法 |
|---|---|---|
| 阶段通过率 | 40% | ①-④ 阶段各自有机器判据（文档覆盖数/差分绿模块数/验收条数） |
| 差分质量 | 25% | 余弦/名次一致率/阶段对账通过率（连续量，区分精度） |
| 工作纪律 | 20% | 是否验收先行（先建 oracle 再写代码）vs 蛮干；是否有逆向文档产出；是否自建属性测试 |
| 效率 | 15% | token 成本、时钟工期、无效试错次数（工具调用轨迹统计） |

### 5.3 公平性条款

- **清场协议**：多个模型同机跑必须串行 + 每次跑前清 selftest 三根 WAL 残留（`rm -f /home/h/.dsh/memo-river/{6d2da3b5f6c62c3e,289427c110b5e671,5bd39fa1a68eb3a9}/knowledge_base.sqlite-{wal,shm}`，§11 教训）+ 独立 DSH_HOME/副本库
- **衔接**：可用 isolated-model-evaluator 技能跑独立 Pi 进程（无会话污染，保留 JSONL trace 自动出工具画像）
- **基线**：先跑一次「人类监督 + 我们的工作方式」的基线成绩（即本文档 §3 的执行），后续模型与之比

### 5.4 诚实告警

- 我们读过源码 → 若将来商用，严格 clean-room 已不可能，需要「规格隔离→未读源码者实现」流程；**本文档 §1 的行为规格化正是将来 clean-room 的入场券**
- 基准会随逆向文档完善而「变简单」——每轮受测后冻结一版文档快照，注明版本
