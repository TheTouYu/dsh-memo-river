## 0. 一句话

LLM agent 记忆系统普遍假设「写入后仍为真」（trust-on-read）。本设计用 0.8B 判别式决策模型（chinese-decision-0.8b）作为**记忆编目员**，在写入时打占有面（possession）标签、召回时打运用面（practice）标签，配合双时间轴系统字段，把「这条记忆是什么、现在还有效吗、此刻有用吗」变成注入块的显式元数据——不改变「结算权在主模型+闸门」的既有分工。

**编目员不当守门员**：任何「要不要注入/要不要结算」的绝对阈值判断被双反证否决（见 §5 红线）。

## 1. 问题定义

- **记忆是时事性的**：写入时为真的状态数字/配置/结论随时间自然失效，这是常态不是异常（D302 案例：D229 修复了 D214 记录的故障，但 D214 至今仍以「当前事实」面目被注入）。
- **模型惰性是结构性的**，三个缺口（设计靶心）：
  1. **看不到信号**——注入的旧记忆与新鲜记忆格式相同，无「可能过时」标记；
  2. **没有义务**——主模型停止条件是回答问题，不含维护知识库；
  3. **验证太贵**——核实旧断言要跑命令查日志，无激励时模型永远选直接引用。
- **量化语境**：病= stale-fact-error（引用过时事实当现状）。MemStrata（arXiv:2606.26511）实测 RAG 架构下 15-40%；药=双时间治理，上限 ~0%（SPO 结构化记忆上达成）。

## 2. 设计哲学：双端两面

知识管理的经典区分（Cook & Brown 1999, Organization Science）：知识的**占有**维度 vs **运用**维度。

- **写入面（possession）**：描述这条记忆本身是什么。只读正文，入库时打一次，之后不变。0.8B 的文本分类甜区。
- **召回面（practice）**：描述这条记忆在当前任务轮里扮演什么角色。读正文+任务上下文，每轮重算，会话态不落盘。
- **系统面**：工程字段（时间戳、链），不用模型，免费。

分面结构而非分类树（Ranganathan 1933 分面分类法）：各面正交、可检验（H5 互信息）。**「召回时再打标签」的认知科学合法性**：记忆再巩固（reconsolidation, Nader et al. 2000, Nature）——提取本身使记忆重新进入可修改窗口；工程对应=召回是更新时效状态的时机（D241：用当前环境反馈修正过去环境的反馈）。

### 3.4 读出渲染形态

```
D214 [快照@10-14][易逝] ⚠️同主题存在1天后写入的D229 判定:SUPERSEDED(p=0.72)
```

静态版（无 0.8B 时的降级）：`[快照@10-14][易逝] ⚠️同主题存在D229`——时间戳+相似度免费。

> **⚠️ H3 判决（2026-10-16，D309）：上述两种读出侧签均不上线。** n=48 盲测（4 臂×2 位置×6 对断言冲突，受试者 glm-5.3-flash，人工重判后）stale 率：无签 17% / 静态时间戳 17% / 语义签 25% / 安慰剂 17%——签零收益，无一格显示签臂>无签臂。机制：**签是断言级（p=0.72），旧篇正文是论证级（实测数字+根因叙事）——断言打不过论证**；三条带签仍误引的直接证据（P2-C/oF、P4-C/oF、P4-C/nF）。强机制另有其人：新篇**正文时效自声明**（「旧报告作废」「已被证伪」「定案」字样）——有自声明对 correct 78% vs 无自声明对 6%，72pp 分组差。⇒ 时效治理的主战场移到**写入面**（H7 闸门强制自声明）。
> **✅ C2 判决（2026-10-16，D311，n=12 复核后 12/12 全对）：「折叠式」验证成立**——旧篇正文不注入、只留 `D214 [已被D230取代，正文折叠]`，stale 0%（对照 A 17%）。同一判定信息，**告知无效、物理缺席有效**（旧论证构造性缺席=误引信息源被移除；受试者还主动复述「已被同主题新结论取代」的正确因果）。⇒ 读出侧正确形态 = L2 实时判定（8122 choice 三态）+ L3 三挡呈现（p≥0.7 折叠 / 0.4-0.7 沉底 / <0.4 正常注入）——**H8 前提验证通过，读出侧复活**（D310 三层流水线）。

## 4. 关键设计决策与理由

### 4.1 半衰期是推导值，不是标注值

让 0.8B 直接预测「这条记忆会活多久」=让它算命；让它标「可证伪的经验断言还是方法论规范」=读文本（甜区）。**特征由模型标，参数由数据定**：桶内统计各类断言形态的实际被取代率，赋每类半衰期先验（学术先例：Chronofy arXiv:2607.20560 的 half-life prior 防 positions/prices/policies 类 stale facts；文献计量学 citation half-life，Price 1965）。

### 4.2 相似度只做检测，判定必须语义

MemStrata 实测：**余弦相似度区分「被矛盾」vs「改写重复」AUROC 0.59≈随机**（矛盾事实比重复更嵌入相似）。⇒ patrol 近重复簇只产生「疑似新旧版本对」候选，**取代判定交给 0.8B（召回面）或主模型（写入面闸门确认）**。此结论同时否决「余弦阈值自动覆盖」类设计。

### 4.3 双端分工与惰性治理

- 写入面标签回答「没人问」缺口 ② 的前半：元数据入库后自动存在于每次注入，不依赖主模型自觉。
- 召回面时效签回答缺口 ①：过时嫌疑主动送到眼前。
- 主模型的结算义务（方案 A 闸门：写入含「已修复/作废/勘误」信号+回注同主题旧篇在场 → 强制回答「推翻了哪几篇」，0.8B 预填三态建议）回答缺口 ③ 的组织面——**闸门保证必答，0.8B 降低答题成本，主模型只确认/否决**。**H3 判决后此项升为全 SPEC 杠杆最高点**：正文时效自声明是有/无自声明对 correct 78%/6% 差异的直接载体，闸门强制「正文首行明写推翻了哪几篇 Dxx」正中机制（H7）。

### 4.4 与既有机制的衔接（不打架）

- **G3（memo_supersede/memo_write.supersedes）**：唯一结算通道不变。0.8B 的 SUPERSEDED 判定是建议值，落账仍需 G3 调用（主模型在场确认）。NEEDS-CONFIRMATION 态=「暗示性变更路由待证据缓冲」（2610.15710 红线）。
- **patrol 近重复巡检**：角色收窄为「候选对生成器」（检测），判定权移交 0.8B。
- **第三刀「回忆后复查」（D234，P0.5）**：本体系是它的基础设施——时效签+取代预判直接喂给「并排摊开」的材料选择。
- **选择权重/recencyBoost 0.05**：H3 已评估——盲测中位置效应**不单调**（P2 首因效应：旧篇根因叙事在前定框架 3/4 stale；P4 双向中弹：画面感与位置无关），未观察到稳定的 LLM recency 偏好方向，工程上无可利用的位置规则。维持 0.05 不动（文献 arXiv:2509.11353 的偏好方向在叙事强度竞争下被淹没）。

### 4.5 论文定位（查证后修正）

不是「提出双时间记忆」（MemStrata 先做，SPO 结构上）；是「**非结构化叙事记忆的时效治理**」：当 agent 记忆是自由文本日记而非三元组时，取代判定必须语义化——我们证明 0.8B 边缘模型 + 三态契约能以 60-120ms 边缘成本逼近结构化方案收益（Mem0 生产延迟预算参照 p99 238ms）。

**被否决/降级项**（诚实记录）：
- **读出侧元数据时效签（含静态时间戳）——被 H3 证伪**（2026-10-16，n=48）：零收益（17%/17%/25%/17%），机制=断言打不过论证。论文叙事相应转向：**负面结果 + 机制发现**——「叙事记忆的时效治理：正文自声明 > 元数据签」，与 MemStrata 的 SPO 结构化取代形成结构化/非结构化对照（结构化记忆里元数据即正文；叙事记忆里正文自声明才是元数据）；
- 「修正环级」（Argyris 单环/双环）独立分面——无 LLM 记忆直接文献，降级为断言形态子特征；
- 近重复簇自动判取代——被 §4.2 否决；
- noul 元门控（「要不要注入」概率阈值）——AUC 0.43 + 概率区间 [0.02,0.81] + ECE 0.06-0.13 双反证，已退役（技能推荐项目 ADR 同款）。

## 5. 红线（违者回炉）

1. **不做绝对阈值判断**：分数只用于重排/标注/预填，不直连删除/注入/退役硬动作（二元门误杀 39.2%，三态降到 15.5%）。
2. **不与检索分加权融合**：D297 实测 RRF 融合 0.333 < 纯重排 0.431，只做轮内重排。
3. **空上下文轮跳过召回面**：D297 实测空 state 时 AUC 掉到 0.43-0.66（≈瞎猜），信号只存在于有真实任务上下文的轮。
4. **写入面标签不进 Tag 闸门**：系统元数据与用户检索锚分离，互不污染。

## 7.5 实验口径与金标契约（2026-10-16 终审四拍，读侧管线遵此执行）

### 7.5.1 H8·L2 截断口径（与既有 AUC 0.745 / P@3 0.431 可比的前提）

| 字段 | 值 | 语义 |
|---|---|---|
| `STATE_CHARS` | **1200（取末尾 1200 字）** | state = **注入块之前**的对话消息，剔 system-reminder / runtime-context 噪声；尾部优先=最近上下文最相关。**红线：注入块本身绝不进 state——否则门卫看着答案答题** |
| `BODY_CHARS` | **600** | 候选日记正文截断（与 H3/C2 盲测同口径） |
| options `desc` | **≤150 字** | HTTP 选项文案口径，≠BODY_CHARS（两回事，勿混） |

依据：build_tests.py 实测口径（读侧核实）。**动这三个数=与既有数字不可比**，新数字须标注重测。

### 7.5.2 L3 切点重标程序

初值 p≥0.7 折叠 / 0.4–0.7 沉底 / <0.4 正常**可按实验数据重标**（跑实验者有权），但每次重标必须**三件套一起写回本节**：新切点 + 数据依据（分布表）+ 日期。**禁止只改切点不留痕**（同验收快照「不许静默自愈」家规）。变更行格式：`[YYYY-MM-DD] 0.7→X / 0.4→Y，依据：<分布/判据>`。

### 7.5.3 金标边界四条（H8 三态金标）

1. **部分取代**（新篇只推翻旧篇一部分，如 P2/D248→D262）→ **NEEDS-CONFIRMATION**（三态为此而造；L3 走沉底档=安全侧——H3 实测部分取代型最难判，无自声明对 correct 仅 6%）。
2. **勘误分两档**：断言级勘误（数字/结论/判据变了）→ **SUPERSEDED**（结论变了就是变了）；文字级勘误（错别字，断言不动）→ **不属取代、不进金标**（编辑修正≠信念修正，Katsuno-Mendelzon 口径；其走 memo_update 语义不产生新篇）。与 H7 信号词表含「勘误」不矛盾——suggest 档只建议、人来终审。
3. **双源互补**（同主题不同侧面且都有效，如 D187/D194「两真一半」）→ **COMPATIBLE**（L3 正常注入）。
