# Windows 本地化与性能基线（2026-11-25）

> 本文记录「把 dsh-memo-river 在裸机 Windows + DSH Desktop 0.2.2-rc.5 上跑起来」这一轮
> 实际做了什么、验证到哪、以及**没验证到**的部分。环境清单（工具链安装路径、代理、嵌入服务）
> 在仓库外的 `E:\h\plugins\SETUP.md`，本文只写仓内相关部分。

## 1. 本轮的四个决定性变化

| 变化 | 为什么 |
|---|---|
| `main` 快进到 `kernel-reimpl`（2026-10-29，P3 收官） | 之前只在 10-14 的 main 上构建；VCP 2.0 复刻（P0–P3：AGS 几何、双场投影、虫洞、conservative-topology-v2.5）全在 `kernel-reimpl` 分支，且它是 main 的严格超集 |
| 插件包自带 `dsh.bundle`（`bundle/cordis.patch.yml`） | 旧布局是「独立 bundle 包 + 插件包」两个包，bundle 包没有依赖声明，`install_bundle` 只会装 bundle 而解析不到插件。现在 `install_bundle <仓库根>` 一步到位：装包、选 bundle、挂预设 |
| bundle 按 **0.2.2 出厂 `standard` 预设**重写 | 旧 patch 是照 0.1.7 的 standard 手抄的，已漂移（`tool-ralph` 不在基础包、`tool-subagent` 的 `backgroundMode` 被 `modelSelection/modelDiscovery` 取代、persona 的 `{{cwd}}` 已被上游注销）。照旧装会在挂载期报错 |
| reimpl 轨接上 `runMemoGeometry` | 旧 `ensureArtifact` 调 `computeEpaBasis` / `computeIntrinsicResiduals` / `computePairwiseSimilarities` 三个上游导出；2.0 起这三件退役，reimpl 内核只导出顶层 `runMemoGeometry(db, modelSig, config, dim)`。不接线 → `assets.*.ok=false`，EPA 基底与内生残差始终为空（近似并列处会翻名次） |

## 2. 构建（Windows）

```powershell
# TypeScript：src → lib（类型来自 app.asar 抽出的 DSH 0.2.2 同版本包）
powershell -NoProfile -ExecutionPolicy Bypass -File E:\h\plugins\.setup\build-win.ps1

# Rust 内核：kernel/ → kernel\memo-kernel.win32-x64-unknown.node（MSVC 工具链）
powershell -NoProfile -ExecutionPolicy Bypass -File E:\h\plugins\.setup\build-kernel.ps1
```

两条红线不变：**勿信 `.bin/tsc`**（编完 grep 新标记非零）；内核产物换名后要能被
`kernel/index.js` 的候选名命中（`memo-kernel.win32-x64-unknown.node`）。

> 注意：`.setup\build-kernel.ps1` 用的是 `Copy-Item` 覆盖。**插件已在跑的生产机上**
> 换内核必须沿用 `kernel/install-kernel.sh` 的「临时文件 + rename」语义（cp 同 inode 会
> 让已 mmap 的代码页被替换 → SIGSEGV）。Windows 侧可用
> `Copy-Item ...tmp; Move-Item -Force tmp dest` 达到换 inode 的效果。

## 5. 平台移植（本轮顺带修掉）

套件原先硬编码 `/home/h/...`、`/var/tmp`、`new URL(...).pathname`（Windows 会变成
`/E:/...`），共 48 个脚本。本轮统一为：

- `fileURLToPath(new URL(...))` 取路径；`pathToFileURL(...).href` 喂动态 `import()`；
- 临时根 `MEMO_ACC_TMP_ROOT > TMPDIR > os.tmpdir()`；
- VCP 根 `MEMO_VCP_ROOT`（缺省 Linux 老路径；Windows 指向不存在的占位，读 rag_params 失败即用缺省）；
- **清理用 `safeRm`**（`scripts/safe-rm.mjs`）：内核按 WAL 契约持有每个 dbPath 的永生
  sqlite 连接，Windows 不允许删除被打开的文件——套件其实全绿却因收尾 `rmSync` 抛 EPERM
  而假红。safeRm 只吞 `EPERM/EBUSY/EACCES/ENOTEMPTY`，句柄随进程退出由 OS 释放。

## 6. 已知限制 / 下一步

1. `dsh-memo-tuner` 客户端未构建（仓库里只有它的 `package.json` 声明），GUI 浮动面板缺席；
   调参路由本身可用（`GET/POST /memo-river/tuning`）。
2. 桌面版把 DSH 封进 `app.asar` 且剥掉 `.d.ts`，类型源靠 `.setup\typeroots` 的
   「npm 装同版本 + junction」维持同源；DSH 升级后要重跑 `link-deps.ps1`。
3. Windows 下临时目录在进程存活期可能删不掉（见 §5），`%TEMP%` 会留少量 `memo-*` 目录。
4. 无远端嵌入回退：8091 挂掉时注入按设计跳过并给模型一条「召回未生效」通知。
