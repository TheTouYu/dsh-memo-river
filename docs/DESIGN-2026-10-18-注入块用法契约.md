# 设计：方法层第一刀 —— 注入块带「用法契约」

> 2026-10-18 开。依据 `docs/PLAN-2026-10-15-记忆系统长期路线.md` §2.1/§2.3。
> **状态：设计稿，待用户拍板后实现。**

## 0. 一句话

注入块现在是**一叠材料**；加一句**用法契约**，告诉模型"拿到这些该怎么用"。
不改选什么、不改给多少——只改**拿到之后怎么想**。

## 1. 为什么是这一刀（判据，不是感觉）

§2.1 的三条实测：

| 动作 | 效果 |
|---|---|
| 往上下文**塞更多资料** | 成功率 **−0.5~−2%**，成本 **+20~23%**（白花甚至有害） |
| **点名「这件事用哪个工具」** | 工具调用 **0.05 → 2.5 次/实例 = 50 倍** |
| 指令堆到 500 条 | 最好模型只有 **68%** 遵从；**~50 条以内**无劣化 |

⇒ **塞资料几乎不改变行为，教方法才改变行为。** 而我们的注入块目前 100% 是资料、0% 是方法。

**成本对比**：加一句话 ≈ **+40~80 token/轮**（相对当前 p50 2986 token 是 +1.3~2.7%）；而 §1 的收益量级是「行为 50 倍 / 成功率 ±2%」。**这是全项目性价比最高的一刀。**

## 2. 现状证据（实测，非推测）

`src/render.ts:86-97` 的 `renderInjection` 渲染结构：

```
⟨memo-river·被动召回 | 本桶=… | Ω=… | mode=… | 动态K×1⟩ | +继承=…
D346「标题」 role=… reward=… tags=…
  正文片段…
[本次未注入 N 条…]
[未注入明细] …
```

**有元数据、有材料、有未注入说明；唯独没有「怎么用」。**

对照：写入侧**已经有**方法契约了（`src/tools.ts:339`）：

```
【写前回注】涉教训类日记，末尾补一行「触发条件→动作」（何时检查 / 发现什么就停 / 做什么）——把教训写成可执行判据。
```

⇒ **写入侧教了怎么记，读出侧没教怎么用。这是不对称的，也是漏掉的杠杆。**

## 3. 要加什么（三选一，请你定）

### 方案 A：最小 —— 一句固定契约（推荐先做这个）

块尾加一行：

```
[用法] 这些是过去的结论，不是当前事实：先判断是否仍适用（看 D 号新旧、是否已被取代），取能改变做法的部分；与现状冲突时以现状为准并记下修正。
```

- **字数**：约 60 字 / 40 token
- **风险**：极低，纯文本
- **可回滚**：配置键 `inject.methodContract: boolean`（缺省 false → 逐字节旧行为）
- **可证伪**：A/B 对照「注入→被用上」指标（已有实验室 `probe-injection-adoption.mjs`）

### 方案 B：中 —— 按条给状态提示

在每条前加极短标记（不替换正文，遵守「证据板不是注解」铁律）：

```
D346 ⚠️3天前「标题」 …
```

- **风险**：中（要判「新旧」，需引入时间判断）
- **注意**：用户明确否决过「注解替代正文」——标记只能**辅助**，不能压掉正文

### 方案 C：大 —— 动态契约（按本轮 Ω/regime 变文案）

Ω 高（结构强）时一句「按结构走」，Ω 低时说「这些只是线索」。

- **风险**：高（文案分支不可证伪，且没有数据支撑哪个档该说什么）
- **结论**：**不建议**。我们连「固定一句有没有用」都还没测过，先别做分支。

## 4. 硬约束（违反会推翻已有结论）

1. **不碰注入内容**：`ids=` 口径、选集、排序、预算一律不动 —— 只加一行文本。
2. **不碰证据板原则**：正文完整保留，契约在块外/块尾，**不缩正文**。
3. **off 档逐字节等于旧输出**：沿用 `c473d32` 的证明法（旧码录 fixture → 新码 off 档断言逐字节相同）。
4. **不新增提醒通道**：是注入块的附属行，不是新的 nudge。
5. **契约文案只写「要做什么」，不写「禁止什么」**（全局守则第 8 条，正向表述）。

## 5. 验收（做到什么算成立）

| 台阶 | 判据 | 命令 |
|---|---|---|
| ① 契约 | off 档逐字节等于旧输出；on 档只多这一行 | `acceptance-queryfield.mjs` 6/6 + `acceptance.mjs` 37/37 |
| ② 挂载 | 真 pre-step 渲染出的块含契约行 | 桶日志 + 会话事件流取样 |
| ③ 效果 | A/B：「注入→被用上」lift 相比基线无劣化或提升 | `probe-injection-adoption.mjs`，n≥10 轮 |

**①②必须过；③是判决依据但需多轮数据，第一天只能给方向。**

## 7. 与既有路线的关系

§2.3 说「方法层收益不随时间恶化，所以排在语料治理之后」——
**语料治理（G1 去重 / G3 取代 / H7 闸门）现已交付**，所以方法层现在正是排在队首的。
本刀是方法层**最小的一步**：只加一句话、只测一句话有没有用，不碰架构。

**如果这一刀测出来没用**，那 §2.1 的「方法层杠杆最大」在我们的场景就不成立，应当回头重估整个路线——**这也是本刀的价值：它是对路线本身的一次廉价检验。**
