# 高质量论文补扫：决策模型 × 记忆系统（生产级 + 真实测试数据口径）

继 Jev-Mem 分析（/tmp/jev-mem-analysis.md）。用户标准：**有实测数据、可复现、最好是生产级使用**，不停留在理论。信源分级：[A]=预注册/同行评审/可复现管线，[B]=有完整实验的自测，[C]=厂商案例（有生产数字但无独立验证）。

## A 级（方法学最硬，直接可迁移）

### 1. Suggested Is Not Superseded（arXiv:2610.15710，2026-10-11，Chen & Le）★ 本轮最重要
**预注册评测：Jev 型决策模型能不能当"记忆退役门"（新发言是否取代旧记忆）**。这精确对应我们 G3 的 memo_supersede。
- 方法：任务契约三分 SUPERSEDED / NEEDS-CONFIRMATION / COMPATIBLE；500 测试对（STALE 变更对+同用户对照），3 个 LLM 标注 + 2 个人类仲裁，预注册假设，3 种金标读法下结论稳健。
- 数字：179 个 STALE 标记变更中仅 72 个达到"确立变更"标准；Jev 对 141 个同会话非变更**零误伤**；**但二元门把 39.2% "仅被暗示变更"的记忆错误退役**；三态决策降到 15.5%，代价是检出率 −15.3 点（超预注册 10 点预算）；held-out 上"不确定升级到推理模型的级联"与单纯调阈值**无差别**（26.8% vs 6.5% dev）。
- **给建造者的结论（论文原话）**：二元分数不应直接接删除；暗示性变更应路由到"待证据"缓冲；不要相信在小规模 dev 数据上选出来的级联。
- **对我们**：memo_supersede 现在是显式声明（人工），若未来自动化，必须用三态门 + 待确认缓冲，不能拿决策模型概率直接退役——这条 A 级证据直接否决"全自动取代"路线。

### 2. When Does Selection Replace Extraction?（arXiv:2609.34227）——已在 D240 详录
预注册、held-out 双基准、配对检验、代码数据全公开：紧预算下决策模型选原始轮次非劣于 LLM 抽取、写成本低 3,061×、重排增益随预算塌缩。维持 A 级。

### 3. Jev-Mem（arXiv:2609.23986，UTD）——上一轮已详录
有代码、全数字、6.6×/−36.7% 效率收益；但单基准单判官自测、无消融 → **A−**（比 15710/34227 的方法学弱一档）。

## B 级（有完整实验，生产相关性高，但需自验）

### 4. Memory Decision Layer / MDL（arXiv:2609.22043，2026-09-18）
- 零参数、纯几何（QR 正交子空间投影融合 relevance/reliability/risk 三信号 + 元工作记忆信号）、白盒、**每决策 +0.14ms**（比嵌入检索快 50×、比 LLM 自评快 4–5 个数量级）；冲突记忆下幻觉率 **−56.04%**、高风险场景近零幻觉；含"风险反转"与显式弃权。
- 与我们盲判发现的"反作用档"正面对应：**该不该信任注入的记忆**这一层完全没人做，MDL 是第一个系统化方案且零训练成本。
- 降 B 的原因：未见代码/数据链接，作者团队无机构信息，实验可复现性待验证。17 页 10 表，多数据集多主流 LLM。

### 5. MemORAI（arXiv:2605.01386，ACL 2026 Findings）
双层压缩选择性写入 + turn 级溯源多关系图 + 查询自适应子图检索（Dynamic Weighted PageRank）。LOCOMO/LongMemEval 双基准 SOTA（摘要口径，具体分差未逐表核）。同行评审背书，但检索仍是生成式/图式，不是决策模型路线。降 B+：与 Jev-Mem 同赛道，数字口径需对齐后才能横比。

### 6. 生产级证据：Mem0 × ZeroEntropy（厂商案例 [C]，但数字真实可审计）
- Mem0：5 万+开发者、**每日 10 亿 token 过记忆层**；生产重排延迟 **p50 75ms / p90 125ms / p99 238ms**（https://www.zeroentropy.dev/articles/mem0-improves-memory-retrieval-accuracy-with-zeroentropy）。
- 关键不是数字本身，而是**选型理由与我们完全同构**：① 校准分数（阈值可跨域统一设定）② 尾延迟稳定 ③ 开放权重可沙箱内先测再切流量。CTO 原话"第一个又准又快又校准的重排器"。
- **佐证我们的路线**：生产级记忆系统真正的瓶颈已被实践验证=检索后那一步的打分质量与延迟分布，正是决策模型/判别器该坐的位置。
- 注意：厂商互吹风险，无独立 A/B 复核；LOCOMO 榜上 Mem0 系分数的口径争议（社区复现分歧）未消。

### 7. 线索级（本轮未核到数字，不计数）
- ACM 可复现性研究 3812836.3814760：各记忆系统"上游忠实复现 vs 原报分数"的具体差值——记忆系统基准分数普遍不可复现的直接证据，值得下次单读。
- MemOS（MemCube 调度、并发代理实验）、Letta/MemGPT 生产部署、Memory is Reconstructed（2606.06036，ICML2026，D239 族①）——维持 D239/D240 原分级。

## 结论
高质量且方法学最硬的三篇（15710 / 34227 / Jev-Mem）**共同指向同一件事**：记忆系统的下一个增量在"检索之后的判别决策层"，且这一层的工程红线已经清楚——**校准概率可用，但二元分数不许直连删除/注入的硬动作；三态 + 待证据缓冲 + 业务数据校准阈值**才是生产形态。Mem0 生产数据佐证该层延迟预算应在 **<250ms p99** 量级——与我们 0.8B 本地 60–120ms/读出的估算兼容。
