### 4. RiverMemo v2 三件套

- **a) AJS 替代 SVD**：SVD=O(N³)（90 年代索引经典）；AJS O(N¹~N²) 预计算自学习（自学习图+双场求解）。向量空间=3072 维「地势图」（呼应 TagMemo v8），查询能量沿图传播、按地形算传播形状；形状匹配找**跨域类比**（细胞鞭毛↔物理仿生结构）。对比 GraphRAG：人工/AI 写边，边数 k 则 1万^k 爆炸；微软要云端月租（费用+延迟+隐私）；Vexus 全本地
- **b) 虫洞算法重推导**：v4 版=能量传递豁免的简单启发式（A 级互证：`memo_sensing.rs` 中 wormhole=decay 0.70+momentum 豁免，正是启发式形态）；新双场求解数学发现**四次方公式**——为什么是四次方不是三次/五次方；作者称「人类第一次用数学解释灵感如何产生」；文档在官方后端
- **c) 圈量子算法**：检索计算量 O(N)→O(resolution)：128 分辨率≈旧全局算法 96% 精度，1024≈99%（10万计算单元只算 1024 次）
- **Omega 泛函 + 拓扑复现**：传播 spike 形状放进 AJS 星云图比对 → 可解释性+可类比性

## 六、与我方复刻的映射（上游 pre-2.0 → 2.0 增量）

本地行为基准（`/home/h/app/VCPToolBox`）已是 **v9.2-rust 时代**：

- `algorithmVersion: "tagmemo.epa-pyramid-spike-fusion-v9.2-rust"`
- EPA basis（K-Means 密度残差采样 + SVD phase + publish cache）
- dualField 双场迭代求解（localMass 0.99 / transferMass 0.94，残差 ~1e-10）
- CSR 图资产（node_ids/row_offsets/targets/weights/inbound/anchor_gain/wormhole_edges/provenance）

### 10.2 两坑（复用价值）
- **假绿**：`(npm ci || npm install) | tail; echo exit=$?` 报 0 但 node_modules 0 项——管道+`||` 吃掉真实退出码；安装类成功判据=对象级读数（`ls node_modules | wc -l`=569 + require 试探）
- **上游 lock 镜像坑**：作者 package-lock 的 resolved 全指 registry.npmmirror.com，本机 npm `EALLOWREMOTE`（remote 类 tarball 禁抓）拒装；修法=sed 域名→registry.npmjs.org（integrity=内容哈希与镜像无关；原 lock 备份 .bak-mirror）。另：npm 默认拦 install-scripts（better-sqlite3 等 4 包 prebuild 受阻但 require 仍可用）
