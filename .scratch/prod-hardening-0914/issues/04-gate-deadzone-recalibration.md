**Status:** 分析完成（2026-09-14，scripts/probe-gate-calibration.mjs 可复现）。推荐 **A：锚拼接 max(gU, gA)@0.55**——误杀 0/17、误放 0/8；实施票待开。

**实测结果（正=17 条生产误杀 gate-skip 全部人工核对为任务内；负=8 条合成任务外文本）**：
- 现状 gU@0.55：误杀 10/17、误放 0——该桶内 gate 从未正确压制过任何东西，只摧毁任务内召回。
- B 阈值下移 0.42：误杀 0 但**误放 8/8**——正样本带（0.44-0.55）与负样本带（0.468-0.536）重叠，任何纯阈值方案都分不开（死刑）。
- A max(gU,gA)@0.55：误杀 0/17、误放 0/8。分离力全部来自助手锚：误杀集 gA=0.709-0.881，负样本 ≈0.47-0.54。
- C 分歧旁路 retr−gU>0.25：仍漏 5/17，最弱；A 已涵盖（A+C 与 A 同分）。
- 附带结构性发现：同为短指令，「继续吧。」恰构成整个查询窗口时走 gateText==queryText 回退（按 window 分数 0.74+ 通过），「按照你的建议来」窗口更丰富时被单独压制——同构消息或过或压，取决于窗口组成，行为混沌。
- 实施口径建议：gA = 最后一条 ≥150 字助手正文的 embedding；会话无助手正文时退回 gU；日志记录 gateVector=spliced 与两锚分数（依赖票02）。
